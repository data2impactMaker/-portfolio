# 이전 기간 업무 요약 (기간·직함 기재 필요)

## 1. 비즈니스 의사결정 지원

- 신규 서비스(ex.네이버 채널링) 런칭 전략수립 및 성과분석
- 마케팅 활동(ex.CRM, 퍼포먼스 마케팅) 성과분석
- 주간/월간 운영 성과보고서 자동화 및 리더회의 보고
- 수요/공급 데이터 기반 상품 가격최적화 전략수립

## 2. 마케팅 / 프로덕트 분석 및 고도화
- 마케팅 전략 수립을 위한 LTV, Cohort 분석
- 프로덕트 개선을 위한 Funnel, Log 분석, A/B 테스트 진행
- RFM, K-means 클러스터링을 활용한 유저 군집화
- 머신러닝을 활용한 주차장 상권 클러스터링

## 3. 데이터 리터러시 증대
- GA4, GTM 활용한 유저 행동로그 설계 및 관리
- Airbridge(MMP), Braze(CRM) 마케팅 솔루션 도입
- Amplitude(PA) 제품분석 솔루션 도입
- BigQuery 데이터마트 구축
- 전사 BigQuery 교육 진행

## 면접 대비 메모
- **5,000만원**: 4~5년차 CRM 마케터 시장 연봉 기준 추정치
- **순효과**: 자연 증분·외부 요인(날씨·트렌드 등)을 걷어낸 우리 액션만의 성과. 대상 예시 — 공급 확대, 상품 조정, CRM 캠페인, 신규 기능
- **회귀**: 인과추론 괄호 안의 회귀는 효과 추정용(회귀 보정). 수요 예측용 회귀와 구분
- **대화형 슬랙봇**: 슬랙봇 '모케터'. 데이터 추출·분석 결과를 대화형으로 답변 + 캠페인 일정·성과 공유
- **Action Item**: 최소 Actionable Insight, 가능하면 팀별(사업·제품) Action Item까지 지정
- **SSOT**: 시멘틱 레이어가 아니라 BigQuery 데이터마트 + GitHub 지표 정의 저장소
- **통합 저장소**: CRM GCS 버킷(campaigns / knowledge / decisions 등). RAG 아님 — 에이전트가 파일을 직접 찾아 읽는 구조
