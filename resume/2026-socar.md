> 구성: 1. AI 활용 → 2. 분석 → 3. 분석 인프라

## 1. AI 기반 CRM 업무 자동화 시스템 구축
- 에이전틱 워크플로우 개발로 CRM 전 과정 자동화
- CRM 캠페인별 성과 지표 정의 및 A/B 테스트 분석 자동화
- 시니어 마케터 1인 채용 없이 운영, 연 약 5,000만원 절감

## 2. 데이터 분석 기반 성과 측정 및 리포팅 고도화
- 인과추론(DID·CUPED·회귀) 기반 본부 액션별 순효과 측정
- CRM 대시보드·대화형 슬랙봇 개발로 마케팅 분석 요청 95% 감축
- Action Item까지 도출하는 분석 리포팅 표준화로 본부 의사결정 가속화

## 3. 지표 체계 설계 및 분석 인프라 구축
- 비즈니스 질문·가설 수립에서 출발하는 이벤트 로그 설계 프레임워크 구축
- BigQuery 데이터마트·Git 기반 지표 SSOT 구축으로 지표 정의 단일화
- 분석 결과·의사결정 맥락 통합 저장소 구축으로 AI 분석 컨텍스트 고도화

## 면접 대비 메모
- **5,000만원**: 4~5년차 CRM 마케터 시장 연봉 기준 추정치
- **순효과**: 자연 증분·외부 요인(날씨·트렌드 등)을 걷어낸 우리 액션만의 성과. 대상 예시 — 공급 확대, 상품 조정, CRM 캠페인, 신규 기능
- **회귀**: 인과추론 괄호 안의 회귀는 효과 추정용(회귀 보정). 수요 예측용 회귀와 구분
- **대화형 슬랙봇**: 슬랙봇 '모케터'. 데이터 추출·분석 결과를 대화형으로 답변 + 캠페인 일정·성과 공유
- **Action Item**: 최소 Actionable Insight, 가능하면 팀별(사업·제품) Action Item까지 지정
- **SSOT**: 시멘틱 레이어가 아니라 BigQuery 데이터마트 + GitHub 지표 정의 저장소
- **통합 저장소**: CRM GCS 버킷(campaigns / knowledge / decisions 등). RAG 아님 — 에이전트가 파일을 직접 찾아 읽는 구조
