이벤트 로그 설계 프레임워크 적용 전후 비교

요구사항 정의서 · 유저플로우 입력으로 KPI 체계와 화면×이벤트 설계안을 표준 양식으로 산출, 미확인 항목은 확인 요청으로 회신

01설계 출발점

현행
출발: 화면 요소 목록
수집 범위: 요소별 전수 수집
KPI 연결: 수집 후 사후 연결
프레임워크 적용 후
출발: 비즈니스 질문과 가설
수집 범위: KPI에 직결되는 이벤트만
KPI 연결: 질문당 KPI 1개, 본부 지표에 연결

02설계 과정

현행
이름 규칙: 담당자마다 제각각
기존 이벤트: 기존 이벤트 미확인 상태로 신규 생성
검증: 적재 후 수기 검증
프레임워크 적용 후
이름 규칙: view·click 2종, 의미는 파라미터
기존 이벤트: 정본 조회 후 재사용 우선
검증: 등록 전 lint 검증 · 실제 수집 여부 조회

03산출물과 소통

현행
산출물: 엑셀 표 · 문서별 양식 상이
빈칸 처리: 추정값으로 작성
소요: 설계 회의 다회
프레임워크 적용 후
산출물: 표준 양식(KPI 체계·화면×이벤트·등록안)
빈칸 처리: 확인 필요 목록으로 회신
소요: 자료 링크 입력 후 설계안 즉시 생성
