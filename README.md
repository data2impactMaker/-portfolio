## About

쏘카에서 모두의주차장 서비스 데이터 분석을 맡고 있습니다.

화려하고 복잡한 분석보다 직관적이고 실행을 이끄는 분석으로 비즈니스 임팩트를 만드는 것을 가장 중요하게 생각합니다. 현재는 AI로 업무 자동화 시스템을 구축하고, 절감한 시간을 비즈니스 성장과 고객 이해에 다시 투입하고 있습니다.

## Highlights

### 1. CRM AI 에이전트 시스템 구축
`AI 자동화` · `Claude Code` · `Braze`

- 기획서·세팅 가이드·발송 공지·성과분석을 에이전트가 생성하고 사람은 게이트에서만 결정
- 데이터 분석가 단독으로 CRM을 월 1건에서 주 6건까지 확대
- 2026년 9월 MAU 102만으로 첫 100만 돌파(CRM 월평균 1.5만 명 기여)

### 2. 마케팅 전담 AI 어시스턴트 '모케터'와 마케팅 허브
`AI 자동화` · `Claude API` · `Slack` · `Cloud Run`

- CRM 요청 접수, 일정·이슈 알림, 분석 보고, 데이터 질의응답을 슬랙에서 수행
- 데이터 추출·분석 요청 95% 감축
- 캠페인 기획·실행·분석과 발송 요청 접수를 허브 웹 하나로 일원화

### 3. 인과추론 기반 본부 액션별 순효과 측정
`데이터 분석` · `층화 무작위 배정` · `CUPED` · `Z-test`

- 층화 무작위 배정과 CUPED로 편향을 줄인 A/B 테스트 판정 표준화
- 수신동의 유도는 손실 강조 문구가 미노출 대비 3.0배
- 구매 증분은 인앱 메시지가 앱푸시 대비 3.4배

### 4. 여의도 불꽃축제 2026 수요 예측과 주차 안내 웹
`AI 자동화` · `Claude Code` · `BigQuery` · `Braze`

- 전년 탐색·판매 데이터로 수요를 사전 점검하고 관람 명소 안내 웹 제작(조회 1.1만 회)
- 인근 권역 거래액 47% 확대로 공급 감소에 따른 매출 감소분 전액 상쇄

### 5. 미결제자 원인분석과 결제전환 전략
`데이터 분석` · `BigQuery` · `카이제곱 검정`

- 미결제 유저의 80%가 접속 1~2회 신규 유저임을 확인해 결제 유도 타겟 선정
- 검색 후 주차장 클릭 전환율이 결제 유저 대비 40.6%p 낮은 이탈 지점 도출
- 인근 공급 부족 검증 후 집중 영업·넛징 CRM으로 대형집객시설 인근 신규 결제자 25.9% 증가

### 6. 지표 체계 설계와 분석 인프라
`데이터 인프라` · `GA4` · `BigQuery` · `GitHub`

- 비즈니스 질문과 핵심 지표 정의에서 출발하는 이벤트 로그 설계 프레임워크
- 데이터마트·Git 기반 지표 SSOT로 리포트·대시보드·슬랙봇·에이전트가 같은 정의 참조
