## 포트폴리오 보는 법

이 레포지토리의 포트폴리오는 **단일 HTML 파일**로 제작되어 있으며, 별도 설치 없이 브라우저에서 바로 열 수 있습니다.

**네비게이션 바**: 스크롤하면 상단에 플로팅 네비게이션이 나타납니다. AI 자동화 · 의사결정 체계 · 지표·인프라 · Visualization 버튼을 클릭하면 드롭다운이 열리고, 세부 프로젝트로 바로 이동할 수 있습니다.

**카드와 라이트박스**: 프로젝트는 2열 카드로 정리되어 있고, 썸네일을 클릭하면 원본 이미지를 크게 볼 수 있습니다. 이미지가 여러 장인 카드는 좌우 화살표로 넘깁니다.

**검색 기능**: `Ctrl + K` (Mac: `Cmd + K`)를 누르거나 상단의 검색 버튼을 클릭하면 검색창이 열립니다. 프로젝트명·목적·결과·도구명을 실시간으로 검색해 바로 이동할 수 있습니다.

**빌드**: 카드 데이터는 `build/build_index.py`에 있으며, `python3 build/build_index.py`로 `index.html`을 다시 생성합니다. 새 이미지를 추가하면 `--thumbs` 옵션으로 썸네일을 함께 만듭니다.

## About

쏘카(SOCAR) CGO 산하 플랫폼데이터팀에서 주차 비즈니스 데이터 분석을 담당하고 있습니다.

화려하고 복잡한 분석보다 **간결하고 직관적인 분석**으로 조직의 성과에 기여하는 것을 지향합니다. 최근에는 AI를 적극 활용하며, 풀어야 할 비즈니스 문제 자체에 더 집중하고 있습니다.

결과물은 이력서 3축과 시각화를 합친 네 영역으로 정리했습니다.

| 영역 | 내용 | 대표 프로젝트 |
|------|------|--------------|
| AI 자동화 | AI 기반 CRM 업무 자동화 | CRM 에이전틱 워크플로우, 데이터업무 슬랙봇, BTS 콘서트 영향분석 |
| 의사결정 체계 | 인과추론 순효과 측정, 슬랙봇·대시보드, 분석 리포팅 | 순효과 측정, 슬랙봇 '모케터', 미결제자 원인분석, 영업관리 프로세스 |
| 지표·인프라 | 이벤트 로그 설계, 지표 SSOT, 통합 저장소 | 이벤트 로그 설계 프레임워크, 데이터마트·Git 지표 SSOT, CRM GCS 통합 저장소 |
| Visualization | Looker Studio · Sheets · Tableau · Kepler.gl 대시보드 | 성과 추적, 공급 관리, 유저 상세 |

## Highlights

### 1. CRM 에이전틱 워크플로우 구축
`AI 자동화` · `Claude Code` · `Braze`

CRM 캠페인 기획·세팅·성과분석 전 과정을 에이전틱 워크플로우로 자동화했습니다.

- 캠페인별 성과지표 정의와 A/B 테스트 분석 자동화
- 시니어 마케터 1인 채용 없이 운영, 연 약 5,000만원 절감 효과

### 2. 인과추론 기반 본부 액션별 순효과 측정
`의사결정 체계` · `DID` · `CUPED` · `회귀 보정`

공급 확대·상품 조정·CRM 캠페인·신규 기능 등 본부 액션의 순효과를 자연 증분과 외부 요인을 제외하고 측정했습니다.

### 3. 대화형 슬랙봇 '모케터'와 CRM 대시보드
`의사결정 체계` · `Claude API` · `Slack` · `Looker Studio`

마케팅 데이터 추출·분석 요청을 대화형으로 처리하고 캠페인 일정·성과를 공유하여 마케팅 분석 요청을 95% 감축했습니다.

### 4. 미결제자 원인분석: 결제전환율 상승 전략 도출
`의사결정 체계` · `BigQuery` · `카이제곱 검정`

미결제/결제 유저군을 접속횟수 · 행동 데이터 · 인근 주차장 공급량 세 축으로 비교 분석하여 결제전환 저해 요인을 구조적으로 분리했습니다.

- 전체 미결제 유저의 80%가 접속 1~2회 신규유저, 저회차 접속자 결제유도 타겟 선정
- 결제퍼널 주차권선택 단계에서 40.5%p Gap 발견, UX 개선 포인트 특정
- 미결제유저의 구매가능 주차장 0~1개 비율이 약 1.8배, 공급부족이 핵심 저해 요인임을 통계적으로 검증

### 5. 지표 체계 설계 및 분석 인프라 구축
`지표·인프라` · `BigQuery` · `GitHub` · `GCS`

- 비즈니스 질문·가설에서 출발하는 이벤트 로그 설계 프레임워크 구축
- BigQuery 데이터마트와 Git 기반 지표 SSOT로 지표 정의 단일화
- 분석 결과·의사결정 맥락 통합 저장소(GCS)로 AI 분석 컨텍스트 고도화
